# 改过名的编号：旧 → 新

2026-09-17 需求和测试用例按模块重新编号。这里只记对应关系，需求和用例本身在各模块文档里。
`P13`（`tools/check_no_stale_ids.py`）读这份的「旧编号」一列，任何仓里再出现旧编号就报红；改名时往这里加一行即可。
